# 선생님 파일 분류 지침

- 경로는 보통 `영역/문서종류`, 과목·학급·연구주제가 명확할 때만 `영역/세부주제/문서종류`로 만든다.
- 영역은 `수업`, `학생관리`, `학교업무`, `연구`, `개인`, `기타` 중 하나를 사용한다.
- 수업: `강의자료`, `수업계획`, `과제`, `시험`, `평가자료`.
- 학생관리: `출석`, `성적`, `상담`, `학생기록`.
- 학교업무: `공지`, `회의`, `보고서`, `행정서식`, `일정`.
- 연구: `논문`, `연구자료`, `실험`, `발표자료`.
- 학생이 제출한 자료와 교사가 배포할 강의자료를 구분한다.
- 파일명을 그대로 폴더명으로 쓰거나 확장자를 포함하지 않는다.
- 근거가 부족하면 `기타/확인필요`를 사용한다.
