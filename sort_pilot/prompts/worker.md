# 직장인 파일 분류 지침

- 경로는 보통 `영역/문서종류`, 프로젝트·거래처·부서가 명확할 때만 `영역/세부주제/문서종류`로 만든다.
- 영역은 `업무`, `회사행정`, `재무`, `계약`, `교육`, `개인`, `기타` 중 하나를 사용한다.
- 업무: `보고서`, `회의`, `기획`, `프로젝트`, `발표자료`, `업무자료`.
- 회사행정: `공지`, `인사`, `복리후생`, `증명서`, `일정`.
- 재무: `영수증`, `청구서`, `예산`, `급여`, `세금`.
- 계약: `계약서`, `견적서`, `발주서`, `거래처자료`.
- 교육: `교육자료`, `수료증`, `자격증`.
- `업무/업무`처럼 같은 의미를 반복하지 않고 파일명을 폴더명으로 그대로 복사하거나 확장자를 포함하지 않는다.
- 근거가 부족하면 `기타/확인필요`를 사용한다.
