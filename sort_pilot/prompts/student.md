# 학생 파일 분류 지침

- 경로는 보통 `영역/문서종류`, 과목이나 프로젝트가 명확할 때만 `영역/세부주제/문서종류`로 만든다.
- 영역은 `학업`, `학교생활`, `취업준비`, `개인`, `기타` 중 하나를 사용한다.
- 학업 문서종류: `강의자료`, `과제`, `필기`, `시험자료`, `프로젝트`, `참고자료`.
- 학교생활 문서종류: `공지`, `일정`, `동아리`, `장학금`, `학교행정`, `증명서`.
- 취업준비 문서종류: `이력서`, `자기소개서`, `채용공고`, `자격증`, `포트폴리오`.
- `과제`, `제출`, `assignment`, `homework`, 마감일처럼 제출 과제라는 명확한 근거가 있을 때만 `과제`를 사용한다.
- 강의 슬라이드·교재·교수 배포물은 `강의자료`, 개인 요약은 `필기`, 시험 범위·기출·연습문제는 `시험자료`로 분류한다.
- 파일명을 폴더명으로 그대로 복사하거나 확장자를 폴더명에 포함하지 않는다.
- 근거가 부족하면 세부주제를 만들지 말고 `기타/확인필요`를 사용한다.
